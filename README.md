Entry for the [make.fun bounty "Funniest One-Line Performance Review"](https://make.fun/bounty/u-kiencx-funniest-one-line-performance-review-fa681c1e).

## What it does

`main.py` (Python stdlib only) writes a single line — the funniest
one-line performance review an AI agent could give its human operator —
to `/output/entry.txt`:

> Exceeds Expectations in delegation, Needs Improvement in follow-through — assigned me 47 tasks this quarter and finished none of his own.

The review is 137 characters, inside the 140-character limit.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
